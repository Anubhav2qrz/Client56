# Janani Priyanka K — Official Portfolio Website

Modern, responsive portfolio web application for **Janani Priyanka K** — University Rank Holder, Broadcast Journalist, Environmentalist, and MBA Professional.

## 🚀 Live Local Server
The website runs as a zero-dependency static web application. To run locally:

```bash
# Option 1: Python
python -m http.server 5173

# Option 2: Node.js (npx)
npx serve .
```

Then navigate to `http://localhost:5173` in any browser.

## 🌟 Built With
- **HTML5**: Semantic tags, Schema.org Person JSON-LD, SEO meta tags.
- **Vanilla CSS**: Custom obsidian dark design system, glassmorphism, responsive masonry grid, micro-animations.
- **Vanilla ES6+ JS**: 28-image archive gallery with real-time filtering, full-screen lightbox modal with zoom, touch gestures & keyboard navigation, animated metrics counter, interactive audio visualizer, dual-page resume viewer.
- **Images**: All 28 photographs extracted from the official dossier PDF, plus dual-page high-resolution resume files located in `extracted_images/`.
